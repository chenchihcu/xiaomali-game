# 小瑪莉 Little Mary 🍎🍊🔔

經典「小瑪莉」水果機的網頁版小遊戲。純 HTML／CSS／JavaScript，**不需要安裝、不需要編譯**，直接用瀏覽器打開就能玩。畫面以 **iPhone 16 Pro Max 直式（Safari）** 為主設計，其他手機與電腦也能玩。外觀為 **霓虹機台** 風格（`theme-neon.css`：玻璃面板、鉻框、霓虹邊光、LED 追光、中獎光爆與上升分數；舞台小遊戲與設定／玩法面板同樣霓虹化；CSS／SVG，無外部圖檔）。在小瑪莉核心之上，融合柏青嫂風三輪 Bonus、Medal 彩池／FEVER、賓果任務、幸運轉輪／轉蛋／骰寶／彈珠台／抽球機／電子輪盤等舞台（特殊停燈觸發），以及倒跑／跳格／假停／雙燈／超跑等跑燈模式（皆可在設定開關）。機框另有跑馬 LED、側燈、假保留燈、FEVER／READY，以及輕量推幣／賽馬視覺點綴。

**中獎分級**：本局得分 ÷ 總押注 ≥3× 顯示 NICE、≥10× BIG WIN、≥25× MEGA WIN，中 JP 顯示 JACKPOT（光芒＋數字跳動＋金幣；點一下可略過；「減少動態效果」時只顯示數字）。純視覺，不影響得分。

**音效與觸覺**：全部音效都以 Web Audio 即時合成（沒有外部音檔）。預設音量 35%，左上角喇叭鍵可一鍵靜音，第一次點擊畫面後才會出聲（iOS 規定）。切到背景時聲音會停止。觸覺回饋可在設定中關閉：Android 用震動，iOS 18 以上用系統輕觸，只在停燈、中獎、鎖燈時觸發。

**HOLD 鎖燈 Bonus**（設定可關）：每次停燈約 0.2%（約每 500 局一次，× 中彩機率）觸發。先鎖 3 盞燈、重轉 3 次；每次重轉，未鎖的燈各有 7.5% 機率鎖上，只要有新燈鎖上，重轉次數就重置為 3。每盞鎖住的燈帶金幣：總押 ×0.1／0.25／0.5／1／3（權重 40／30／20／8／2，至少 1 分）。24 盞全亮時另得 JP 彩池（JP 關閉或彩池為 0 時改得 50× 總押）。平均每次約 6.2× 總押，全亮率約 1.3%；標準難度 RTP 約 +1.3 個百分點（`node sim.js` 會列出）。

> ⚠️ **免責聲明：本遊戲僅供娛樂。所有分數（CREDIT／WIN／JP）皆為虛擬點數，不能儲值、不能兌換任何金錢或獎品，非真實賭博。**

## 快速開始（本機）

**方法 A：直接打開**  
雙擊 `index.html`，用 Chrome／Safari／Edge 打開即可。

**方法 B：開個本機伺服器（建議）**

```bash
cd xiaomali
python3 -m http.server 8000
# 瀏覽器打開 http://localhost:8000
```

**用手機測試：** 手機和電腦連同一個 Wi‑Fi，Safari 打開 `http://<電腦區網 IP>:8000`。

## 怎麼玩

| 操作 | 說明 |
|---|---|
| **水果鍵（下方 8 個）** | 點一下押 1 分（從 CREDIT 扣），**按住可連續加注**，每種最多 99。 |
| **全押** | 8 種圖案各加押 1 分。 |
| **加倍** | 目前有押的圖案各再加同等押分（夠分才加）。 |
| **續押** | 依上一局押注再扣分押上（不自動開始）。 |
| **自動** | 連續「續押＋開始」；分數不足或再按一次可停。中 WIN 會先得分再繼續。 |
| **清除** | 取消這局押注，分數退回 CREDIT。 |
| **開始** | 外圈 24 格跑燈 + **中央三轉盤**同時轉動後停下。 |
| **得分** | WIN → CREDIT |
| **小 / 大** | 1–4 小、6–9 大；中×2、錯歸零、5 和 |
| **開分** | 虛擬加 CREDIT（點一下 +100，按住 +500）。 |
| **洗分** | WIN→CREDIT 後將 CREDIT 清零（虛擬洗分）。 |
| **🔊** | 音效／BGM（iPhone 靜音時可能無聲） |
| **⚙️** | 難度、中彩／連跑／JP、權重、押注、音量、音樂 |

- 起始 **CREDIT 1000**，存在瀏覽器 localStorage。
- 上一局押注會保留（數字變暗），直接按「開始」再玩；點水果鍵則重新押注。

### 設定

- **輕鬆／標準／困難**：停燈權重與中彩／連跑／JP 預設
- **中彩機率**：送燈／開火車／三元四喜／舞台觸發加乘
- **連跑機率**：連跑／大 ONCE MORE／超跑觸發加乘
- **JP 累積**：彩池成長倍率
- **玩法開關**：ONCE MORE 系、中彩、JP、三輪 Bonus、FEVER、賓果、跑燈模式
- **停燈權重**：各圖案／ONCE MORE／小圖 ×3 相對停燈機會
- **起始 CREDIT／單次押注**：重設分數與每次押注單位
- **音效／BGM 音量**、**音樂曲目**（程序合成）
- 設定存 `localStorage`（`xiaomali.settings.v1`）

### 電腦鍵盤

`1`–`8` 押、`A` 全押、`C` 清、空白／Enter 開始、`S` 得分、`←`小 `→`大、`D` 加倍、`R` 續押、`T` 自動、`O` 開分、`W` 洗分

## 檔案結構

```
index.html     頁面骨架（含設定／玩法 dialog、中央三轉盤）
styles.css     直式實體機台版面（上方 WIN/CREDIT、跑燈盤、倍率列、按鍵台）
theme-neon.css 霓虹機台外觀（覆蓋 styles.css 的顏色與材質；動畫只用 transform／opacity）
engine.js      純邏輯：盤面權重、設定、中彩、JP、舞台（三輪／FEVER／賓果／超跑等）、RTP 模擬（無 DOM）
game.js        UI：跑燈模式、轉盤、舞台演出、賓果板、音效／BGM、設定、押注與比大小
sim.js         Node 平衡檢查：node sim.js [rounds]
icon.* / manifest.webmanifest
AGENTS.md      給 Cursor／Codex 維護者的說明
```

調整機率：改 `engine.js` 的 `TRACK[].w`、`PRESETS`，或用遊戲內設定。改完可跑 `node sim.js` 看 RTP。
