# 小瑪莉 Little Mary 🍎🍊🔔

經典「小瑪莉」水果機的網頁版小遊戲。純 HTML／CSS／JavaScript，**不需要安裝、不需要編譯**，直接用瀏覽器打開就能玩。畫面以 **iPhone 16 Pro Max 直式（Safari）** 為主設計，其他手機與電腦也能玩。外圈彩燈與操作鍵採 **擬真街機** 立體亮面（CSS／SVG，無外部圖檔）。機框另有跑馬 LED、側燈、假保留燈與 FEVER／READY 閃示（純視覺）。

> ⚠️ **免責聲明：本遊戲僅供娛樂。所有分數（CREDIT／WIN／JP）皆為虛擬點數，不能儲值、不能兌換任何金錢或獎品，非真實賭博。**

**線上遊玩：** https://chenchihcu.github.io/xiaomali-game/

**原始碼：** https://github.com/chenchihcu/xiaomali-game

## 快速開始（本機）

**方法 A：直接打開**  
雙擊 `index.html`，用 Chrome／Safari／Edge 打開即可。

**方法 B：開個本機伺服器（建議）**

```bash
cd xiaomali
python3 -m http.server 8000
# 瀏覽器打開 http://localhost:8000
```

**用手機測試：** 手機和電腦連同一個 Wi‑Fi，Safari 打開 `http://<電腦區網 IP>:8000`。

## 怎麼玩

| 操作 | 說明 |
|---|---|
| **水果鍵（下方 8 個）** | 點一下押 1 分（從 CREDIT 扣），**按住可連續加注**，每種最多 99。 |
| **全押** | 8 種圖案各加押 1 分。 |
| **加倍** | 目前有押的圖案各再加同等押分（夠分才加）。 |
| **續押** | 依上一局押注再扣分押上（不自動開始）。 |
| **自動** | 連續「續押＋開始」；分數不足或再按一次可停。中 WIN 會先得分再繼續。 |
| **清除** | 取消這局押注，分數退回 CREDIT。 |
| **開始** | 外圈 24 格跑燈 + **中央三轉盤**同時轉動後停下。 |
| **得分** | WIN → CREDIT |
| **小 / 大** | 1–4 小、6–9 大；中×2、錯歸零、5 和 |
| **開分** | 虛擬加 CREDIT（點一下 +100，按住 +500）。 |
| **洗分** | WIN→CREDIT 後將 CREDIT 清零（虛擬洗分）。 |
| **🔊** | 音效／BGM（iPhone 靜音時可能無聲） |
| **⚙️** | 難度、中彩／連跑／JP、權重、押注、音量、音樂 |

- 起始 **CREDIT 1000**，存在瀏覽器 localStorage。
- 上一局押注會保留（數字變暗），直接按「開始」再玩；點水果鍵則重新押注。

### 跑燈／中彩（設定可開關）

| 名稱 | 效果 |
|---|---|
| ONCE MORE | 免費再跑 1 次；可再停 ONCE MORE 連續加碼（有上限） |
| 連跑 | 停 ONCE MORE 時隨機再跑 2–4 次，每次停燈有押就計分 |
| 大 ONCE MORE | 停 ONCE MORE 時保證再跑 ≥3 次 |
| 送燈 | 額外亮 1～3 盞計分 |
| 開火車 | 停點後連燈計分 |
| 三元四喜 | 成套亮燈計分 |
| JP | 押分累入彩池；停大 BAR 且押 BAR 可拿走 |

畫面上會顯示 **「再跑 N 次」** 倒數。

### 設定

- **輕鬆／標準／困難**：停燈權重與中彩／連跑／JP 預設
- **中彩機率**：送燈／開火車／三元四喜觸發加乘
- **連跑機率**：連跑／大 ONCE MORE 觸發加乘
- **JP 累積**：彩池成長倍率
- **停燈權重**：各圖案／ONCE MORE／小圖 ×3 相對停燈機會
- **起始 CREDIT／單次押注**：重設分數與每次押注單位
- **音效／BGM 音量**、**音樂曲目**（程序合成）
- 設定存 `localStorage`（`xiaomali.settings.v1`）

### 電腦鍵盤

`1`–`8` 押、`A` 全押、`C` 清、空白／Enter 開始、`S` 得分、`←`小 `→`大、`D` 加倍、`R` 續押、`T` 自動、`O` 開分、`W` 洗分

## 檔案結構

```
index.html     頁面骨架（含設定／玩法 dialog、中央三轉盤）
styles.css     直式實體機台版面（木框機殼、上方 WIN/CREDIT、跑燈盤、倍率列、按鍵台）
engine.js      純邏輯：盤面權重、設定、中彩、JP、RTP 模擬（無 DOM）
game.js        UI：跑燈、轉盤、音效／BGM、設定面板、押注與比大小
sim.js         Node 平衡檢查：node sim.js [rounds]
icon.* / manifest.webmanifest
AGENTS.md      給 Cursor／Codex 維護者的說明
```

調整機率：改 `engine.js` 的 `TRACK[].w`、`PRESETS`，或用遊戲內設定。改完可跑 `node sim.js` 看 RTP。
